# Políticas de Privacidade

Páginas estáticas com as políticas de privacidade dos aplicativos de Leandro Nazareth,
publicadas via GitHub Pages.

- `index.html` — índice com link para cada app.
- `<nome-do-app>.html` — política de privacidade de cada app (uma página por app).

Para adicionar um novo app: crie `<nome-do-app>.html` seguindo o estilo de
`calcula-obra.html` e adicione um link em `index.html`.
